# Low-Text Keynote / Live Talk Decks

Use when the presenter will do most of the talking and slides are visual anchors.

## Principles

- Big headline, image, number, or question.
- Minimal bullets.
- More slides are acceptable if each slide is lighter.
- Use rhythm: statement, proof, breath, transition.
- Speaker detail stays off slide.

## Good Patterns

- Single phrase
- One icon and one label
- Full-bleed image
- Big number
- Question mark
- Two-option contrast

## Avoid

- Paragraphs.
- Dense comparison tables.
- Multiple ideas per slide.
