# Product Demo / Launch / Roadmap Decks

Use for product launches, feature walkthroughs, roadmap presentations, demo scripts, and product marketing.

## Principles

- Show the product or the real object early.
- Make the first slide signal the product clearly.
- Split roadmap into now / next / later when useful.
- Use screenshots, flows, and interface states.
- Keep benefits tied to user jobs, not generic features.

## Common Slides

- Product promise
- User pain
- Demo flow
- Feature set
- Roadmap
- Adoption / distribution
- Call to action

## HTML Opportunities

- Use interactive mockups if useful.
- Use step-by-step reveal through slides rather than animation dependency.
- Link sections with hash jumps for demos.
