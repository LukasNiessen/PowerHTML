# Strategy / Executive / MBB-Style Decks

Use for strategy, transformation, operating model, leadership, consulting, board, or executive audiences.

## Principles

- Lead with the answer.
- Use action titles: “Margin expands when pricing and mix move together,” not “Margin analysis.”
- Keep a tight storyline: situation, complication, resolution.
- Use MECE grouping when it improves clarity.
- Use pyramid logic: recommendation first, supporting arguments beneath.
- Use evidence only where it earns attention.

## Style

- Calm, precise, spacious.
- High contrast and restrained accents.
- Few decorative elements.
- Charts/tables should look authored, not default Office.

## Common Slides

- Executive summary
- Current state
- Issue tree / drivers
- Options / tradeoffs
- Roadmap
- Decision or ask

## MBB-Inspired Defaults

- Bain-like: simple, memorable, concrete, with a clear “so what.”
- McKinsey-like: top-down, answer-first, structured evidence.
- BCG-like: strategic framing, market logic, bold synthesis.

These are heuristics, not brand templates.
