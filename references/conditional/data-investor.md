# Data / Investor / Metrics Decks

Use for financial, investor, KPI, benchmark, market, traction, or performance decks.

## Principles

- One data insight per slide.
- Use the chart form that matches the question.
- Label the insight directly; do not force legend hunting.
- Put sources and dates where needed.
- Avoid pseudo-charts when real charts/tables are clearer.

## Common Patterns

- Traction: active users, downloads, revenue, pipeline, retention.
- Benchmark: ranked bars or clean comparison table.
- Funnel: stage conversion.
- Time trend: line or column chart with clear annotation.
- Targets: large metric tiles can work when they are few and comparable.

## Visual Rules

- No default chart colors.
- No cramped axes.
- Use enough context to make a metric meaningful.
- If data is uncertain, label it as target, estimate, or snapshot.
