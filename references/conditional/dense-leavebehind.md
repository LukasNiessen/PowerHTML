# Dense Leave-Behind Decks

Use when the deck must stand alone without the presenter.

## Principles

- More text is acceptable, but structure it.
- Use summaries, captions, sources, and clear sectioning.
- Prefer tables/diagrams over paragraphs.
- Include enough context to be understood later.

## Structure

- Executive summary.
- Section openers.
- Evidence slides.
- Appendix if needed.

## HTML Considerations

- Consider print styles if the deck will be exported to PDF.
- Allow vertical scroll within appendix slides only if explicitly needed.
- Keep presentation mode readable.
