# Technical / Security / Developer Tool Decks

Use for engineering, security, infrastructure, open-source, AI agents, developer tools, or technical kickoff decks.

## Principles

- Respect technical specificity without crowding slides.
- Use diagrams, code fragments, architecture maps, timelines, and threat models when useful.
- Separate live headline slides from detailed appendix or notes.
- Make status explicit: released, unreleased, alpha, blocked, shipped, merged, planned.

## Security Topics

- Supply chain risk
- Secret exposure
- Dependency compromise
- CI/CD hardening
- Agentic security workflows
- Quality gates
- Blast-radius reduction

## Open-Source Slides

- Show stars/downloads only when they support the story.
- Compare competition fairly.
- Include ownership, onboarding, roadmap, and promotion loops.
- Treat distribution as part of the product.

## Visual Style

- Dark product-style decks work well when contrast is high.
- Use logos and real project assets.
- Avoid fake cyber decoration unless the user asks for it.
